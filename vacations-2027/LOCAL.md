# Отпуска 2027 — программа для компьютера

Версия **1.0.2**: включены 73 сотрудника с должностью «Врач» из PDF; к прежним 30 добавлены 43. Рабочие дни в новогодние праздники выбираются с 31 декабря 2026 по 10 января 2027 включительно. Исправление чтения UTF-8 на Windows с кодировкой CP1251 сохранено.

## Windows 10/11, 64 бита

1. Скачайте архив `vacations-2027-windows-x64-v1.0.2.zip`.
2. Нажмите на архив правой кнопкой → **Извлечь всё**. Распакуйте в обычную папку, например «Документы → Отпуска 2027».
3. В распакованной папке дважды щёлкните **START.bat**.
4. Программа сама откроется в браузере. Оставьте окно запуска открытым, пока работаете. Для завершения закройте его; данные останутся на компьютере.

Python, зависимости и список сотрудников уже включены. Отдельная установка, аккаунт Render, доступ в интернет и права администратора не нужны. Не запускайте файл прямо внутри ZIP — сначала распакуйте весь архив.

Если браузер не открылся автоматически, скопируйте адрес из окна запуска в адресную строку браузера. Обычно это `http://127.0.0.1:8765`. Это адрес только вашего компьютера, а не сайт в интернете. Если порт занят, программа выберет свободный из диапазона 8765–8784 и покажет его в окне.

Повторный запуск START.bat открывает уже запущенную программу с той же базой, не создавая отдельный список.

Для обновления закройте старое окно программы, распакуйте новый архив в новую папку и запустите START.bat из неё. Папку данных `%LOCALAPPDATA%\Medsonar\Vacations2027` не удаляйте: новая версия подхватит существующие ответы и один раз добавит новых врачей. Сохраняются прежние ФИО и исправления кадровика, лимиты дней, анкеты и добавленные вручную сотрудники. После неудачного первого запуска программа автоматически загрузит весь список в оставшуюся пустую базу.

## Как пользоваться

- **Сотрудник:** введите свою фамилию. Затем выберите периоды отпуска на 2027 год и укажите, когда планируете работать с **31 декабря 2026 по 10 января 2027**. Можно сохранить черновик или отправить анкету в отдел кадров.
- **Отдел кадров:** логин **admin01**, пароль **admin01**. Здесь доступны все сотрудники, их анкеты, календарь, изменение лимита дней и выгрузка CSV, который открывается в Excel.

Включены **73 врача** из переданного PDF. Служебные профили кабинетов не являются сотрудниками и в список не включены. Николаенко — **Оксана Владимировна**; прежние уточнения списка сохранены. При первом запуске анкеты пустые, при обновлении остаются заполненные ответы. Однофамильцы дополнительно выбирают полное ФИО при входе.

## Где сохраняются данные

Данные сохраняются в профиле текущего пользователя Windows:

```text
%LOCALAPPDATA%\Medsonar\Vacations2027
```

Чтобы открыть эту папку, нажмите **Win+R**, вставьте путь выше и нажмите **Enter**. Основная база — `vacations.sqlite3`. Файл `.session-key` хранит ключ локальных сессий.

Перезапуск программы, закрытие браузера и замена папки приложения не удаляют ответы. В пустую базу загружается весь список; в существующую однократно добавляются новые сотрудники этой версии списка. Повторные запуски не создают дубликатов и не возвращают прежние ФИО после исправлений кадровиком.

**Резервная копия и перенос на другой компьютер:** закройте окно программы и скопируйте всю папку `%LOCALAPPDATA%\Medsonar\Vacations2027` в закрытое место. На новом компьютере распакуйте приложение, до первого запуска восстановите эту папку в профиле пользователя и запустите START.bat. Копия содержит ФИО и ответы — не размещайте её в открытом доступе.

Приложение доступно только на компьютере, где оно запущено. У каждого пользователя Windows своя база. Для общего учёта в локальной версии используйте один компьютер и один профиль Windows; отдельные копии на разных компьютерах автоматически не синхронизируются.

## Состав программы

В `runtime/` находится официальный Python для Windows и библиотеки; не удаляйте эту папку. `private/initial-roster.json` содержит только необходимые ФИО, без исходных PDF и XLSX. `static/` и `templates/` — интерфейс. Манифест `BUILD-INFO.json` описывает версию и источники поставки. Лицензия Python находится в `runtime/LICENSE.txt`, лицензии библиотек — в соответствующих каталогах `.dist-info`.

## Для разработчика: запуск исходников

Есть отдельный архив исходников, подходящий для Windows, macOS и Linux с установленным Python 3.12. Используется Waitress; Gunicorn и Docker для локальной программы не нужны.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\python -m pip install --require-hashes -r requirements-local.lock
.venv\Scripts\python run_local.py
# macOS / Linux:
.venv/bin/python -m pip install --require-hashes -r requirements-local.lock
.venv/bin/python run_local.py
```

На macOS база находится в `~/Library/Application Support/Medsonar/Vacations2027`, на Linux — в `$XDG_DATA_HOME/medsonar-vacations-2027` или `~/.local/share/medsonar-vacations-2027`. Для отдельной тестовой базы доступны параметры `--data-dir ПУТЬ --port 8765 --no-browser`.
