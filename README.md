# Отпуска сотрудников · 2027

[Открыть версию 1.0.2 для Windows 10/11, 64 бита](https://github.com/Yurakostolom/Lesson_3/blob/main/downloads/vacations-2027-windows-x64-v1.0.2.zip)

В версии **1.0.2** добавлены все сотрудники с должностью «Врач» из PDF: список содержит **73 человека**, на 43 больше прежнего. Период выбора работы в новогодние праздники — **31 декабря 2026 — 10 января 2027**, включительно. Исправление кодировки Windows сохранено.

Для обновления закройте старое окно программы, распакуйте новую версию в отдельную папку и запустите START.bat. Новые сотрудники добавятся автоматически; заполненные анкеты, исправления кадровика и дополнительные сотрудники сохранятся. Папку данных в профиле Windows удалять не нужно.

На странице архива нажмите **Download raw file** — значок стрелки вниз справа вверху. Открывайте её в том же браузере и аккаунте GitHub, где видны папки этого репозитория. Прямая ссылка на домен `raw.githubusercontent.com` может возвращать404; используйте страницу файла и кнопку скачивания GitHub.

После скачивания нажмите на ZIP правой кнопкой → **Извлечь всё**. В распакованной папке запустите **START.bat**. Программа откроется в браузере; окно запуска оставьте открытым. Python и библиотеки включены, подключение к интернету для работы не требуется.

- Сотрудник входит по фамилии, выбирает даты отпусков на 2027 год и дни работы в новогодние праздники.
- Во вкладке отдела кадров логин **admin01**, пароль **admin01**. Доступны общая сводка, календарь, редактирование лимита дней и CSV для Excel.
- Данные сохраняются в `%LOCALAPPDATA%\Medsonar\Vacations2027` и остаются после закрытия программы.

Исходники и полные инструкции: [vacations-2027](vacations-2027/), [локальный запуск](vacations-2027/LOCAL.md), [размещение на Render](vacations-2027/RENDER.md). Для Render укажите **Root Directory: `vacations-2027`** при создании Docker Web Service; конфигурация с диском находится внутри этой папки.

Прежние учебные файлы репозитория сохранены.
